# ✨ Funciones incluidas en esta versión

KeySafe Pro 1.0.0 es la primera versión oficial del proyecto e incorpora un sistema completo de almacenamiento local, resguardo cifrado y gestión de credenciales para Windows.

### 🛡️ Bóvedas Cifradas con AES-256-GCM & PBKDF2

Permite almacenar e hiper-proteger tus contraseñas, usuarios, enlaces y notas confidenciales dentro de un archivo SQLite inexpugnable.

El sistema utiliza algoritmos de cifrado de estándar gubernamental y militar (**AES-256-GCM** con **PBKDF2-HMAC-SHA256** a 600,000 iteraciones) para asegurar que nadie sin la clave maestra pueda acceder a tu información.

Cada secreto se cifra de manera individual con un nonce aleatorio de 12 bytes, garantizando que el archivo sea totalmente invulnerable incluso en caso de robo físico del dispositivo.

### 🔄 Almacenamiento 100% Local y Portabilidad Total

Incluye un sistema independiente que no requiere conexión a Internet ni almacenamiento en servidores de terceros.

Permite guardar y trasladar tu bóveda (`.db`) a cualquier unidad portatil, disco externo o servicio de respaldo personal de manera fácil y segura.

Esta función es ideal para:

* 🏢 Entornos corporativos y trabajo remoto
* 🎓 Estudiantes y docentes con credenciales académicas
* ⚖️ Abogados, contadores y profesionales de la salud
* 🎒 Usuarios que gestionan múltiples cuentas y requieren privacidad total

### 🔑 Generador Inteligente y Auditoría de Seguridad

Incorpora un generador de contraseñas de alta entropía con medidor de fortaleza visual en tiempo real.

Incluye una herramienta de auditoría integrada que analiza tus entradas para identificar contraseñas débiles o duplicadas entre servicios, permitiendo corregirlas inmediatamente.

# ⭐ Características Principales

### 🔐 Cifrado y Seguridad de Grado Militar

* Protege credenciales y notas dentro de un contenedor `.db` cifrado.
* Cifrado simétrico robusto mediante **AES-256-GCM**.
* Derivación de clave maestra con **PBKDF2-HMAC-SHA256** (600,000 iteraciones).
* Auto-bloqueo tras 5 minutos de inactividad para prevenir acceso no autorizado.
* Limpieza automática del portapapeles a los 20 segundos de copiar una clave.

### 💾 Gestión de Credenciales y Portabilidad

* Almacenamiento totalmente offline y privado en base de datos SQLite.
* Clasificación por categorías (Bancos, Correos, Redes Sociales, Trabajo, etc.).
* Búsqueda en tiempo real por servicio, usuario o URL.
* Exportación y restauración segura de copias de respaldo.

### 🛡️ Auditoría y Generación de Contraseñas

* Generador de contraseñas de longitud y complejidad personalizable.
* Indicador visual de fortaleza (Débil, Media, Fuerte).
* Módulo de auditoría que detecta claves débiles o reutilizadas entre servicios.

### ⚙️ Gestión de Acceso y Licencias

* Verificación de licencia amarrada al hardware (ID único de equipo).
* Licencias firmadas criptográficamente con **RSA-4096**.
* Interfaz intuitiva y moderna con tema oscuro (Dark Navy / Cyan).

### 🚀 Rendimiento Optimizado

* Operaciones de cifrado y lectura instantáneas.
* Mínimo consumo de recursos del sistema.
* Operativo 100% sin conexión a Internet.

### 🔑 Recuperación y Cambio de Clave

* Permite cambiar la clave maestra recifrando automáticamente toda la base de datos en una sola transacción.
* Verificación de la integridad de la bóveda al iniciar.

# ⚠️ Nota de Seguridad

> [!CAUTION]
> KeySafe Pro interactúa directamente con el sistema de archivos de Windows y utiliza librerías criptográficas de bajo nivel para derivar claves y cifrar datos en tiempo real.
>
> Debido a este comportamiento técnico y al empaquetado del ejecutable, algunos antivirus o soluciones de seguridad pueden mostrar alertas preventivas o falsos positivos.

> [!NOTE]
> KeySafe Pro es un proyecto independiente en constante evolución.
>
> Esta primera versión oficial aún no cuenta con una firma digital de código (Code Signing Certificate), por lo que Windows SmartScreen puede mostrar advertencias preventivas al ejecutar el archivo descargado.
>
> Estas advertencias forman parte de las medidas de seguridad estándar de Windows y no indican la presencia de software malicioso.
>
> La incorporación de firma digital se encuentra prevista para futuras versiones del proyecto.
